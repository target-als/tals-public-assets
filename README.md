# TALS Public Assets

Public branding assets for the Target ALS Research Assistant (TARA) and
related Target ALS tools.

## Purpose

This repository hosts approved, non-sensitive assets that must be publicly
accessible, such as Google Chat application icons.

## Usage

Use the raw GitHub URL when referencing an asset:

```text
https://raw.githubusercontent.com/OWNER/REPOSITORY/main/ASSET.png
```

## Content policy

Only approved public branding materials may be stored here.

Do not add:

- Credentials, tokens, or configuration secrets
- Internal documents or organizational data
- Patient, participant, or sample data
- Personal or sensitive information
- Proprietary datasets
- Application logs or diagnostic output

All repository contents should be treated as publicly accessible.
